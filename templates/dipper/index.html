Dipper Data Collector

This app helps you collect data from your systems so that it can be used for performance analysis and reporting.

Using this Application

During your engagement with Percona, we may ask you to run several scripts, which can be executed from this page.

Scripts

pcs-collect-environment-*.sh This script collects information about the state of the hardware, operating system, database setup and schema.
pcs-collect-pmm-*.py This script will use PMM's API to render, and download various graphs.

Requirements

sudo is required to run the pcs-collect-environment.sh script.
Please ensure that you have a ~/.my.cnf properly configured to allow the script to connect to a MySQL database.
