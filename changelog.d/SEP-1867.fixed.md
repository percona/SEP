Resolve a single-user lookup through the organization user listing when Grafana's service account is scoped to one organization instead of holding Server Admin, so an admin can retrieve another user's record where the request previously failed with a permission error. Deployments whose service account holds Server Admin are unaffected: their lookup path is unchanged. A record resolved through the organization listing carries that organization's role only, so a Grafana Server Admin is reported at their organization rank rather than as a SEP super admin, and it is read from the same listing cache the user list already uses, so a rename in Grafana can resolve stale for up to five minutes. An unreadable Grafana user list is now reported as an upstream gateway error rather than an unhandled server error.
