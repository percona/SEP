User identities now expose an ordered `role` (`none` < `viewer` < `editor` < `admin` < `super_admin`) alongside the `isAdmin` flag, which is derived from it. With the Grafana provider the role a response carries depends on how the identity was loaded: `GET /api/users/` reports the org role, `GET /api/users/{username}` ranks the server-admin flag alone because the lookup endpoint carries no org memberships, and a bearer-authenticated identity — including `GET /api/users/me` — reports the role its session assertion carries. Casdoor exposes no role concept, so a Casdoor identity is `admin` or `viewer` throughout. `isAdmin` is unchanged on every path.
