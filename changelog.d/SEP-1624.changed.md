Snippets list sorting and searching now run through the shared core list-query framework, with deterministic ordering across pages; the approval, service-type and uncategorized filters and the service-types facet are unchanged. Every snippet listing — the JSON list endpoint, the legacy snippets page, the Collect Diagnostic Data category listing and the alert-troubleshooting pick-lists — now shares that one ordering, so unapproved snippets sort consistently last on SQLite and PostgreSQL, and ties break on the snippet id rather than a non-unique timestamp.
