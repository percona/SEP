The MySQL Backups plugin is now available in the new React UI under `/plugins/mysql_backups`, schema-driven via the shared plugin framework with per-mode (Mydumper / XtraBackup / Binlog) field gating. A JSON API surface is exposed at `/api/plugins/mysql_backups/` (`GET /schema`, `GET /`, `GET /{task_name}`, `POST /`, `POST /{task_name}/execute`, `DELETE /{task_name}`). The legacy Jinja2 routes under `/mysql_backups/` remain functional but are now marked deprecated (RFC 8594 `Deprecation` response header and in-page banner).
