MySQL Backups plugin migrated to the new React UI under `/plugins/mysql_backups`, schema-driven via the shared plugin framework with per-mode (Mydumper / XtraBackup / Binlog) field gating. A JSON API surface is exposed at `/api/plugins/mysql_backups/` (`GET /schema`, `GET /`, `GET /{task_name}`, `POST /`, `POST /{task_name}/execute`, `DELETE /{task_name}`) with validated pagination and tolerant YAML parsing. The `upload` MultiChoice contract is explicit: at least one provider must be selected, and destination fields (`s3_bucket`, `gs_bucket`, `rsync_path`, …) are hidden until the matching provider is ticked — wired by a new schema-DSL `contains(field, value)` predicate. The React service selector now routes through a new `GET /api/sep/services/` gateway so the frontend no longer bypasses the SEP layer. The legacy Jinja2 routes under `/mysql_backups/` remain functional but are marked deprecated (RFC 8594 `Deprecation` response header and in-page banner).
