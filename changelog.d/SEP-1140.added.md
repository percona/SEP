Inventory MySQL Topology view: a new "Topology" tab on the Inventory page renders an interactive React Flow graph of MySQL replication, dual-primary pairs, and Percona XtraDB Cluster groups, collected on demand by sharded `run-python` tasks dispatched to executor hosts and progressively streamed to the UI over Server-Sent Events. Replaces the manual `db_tree.py` text-tree workflow with a cached, refreshable visualization that reuses the same `~/.my.cnf` / `~/.mylogin.cnf` credential lookup as `MySQLSyncer`.
