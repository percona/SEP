`DELETE` on an inventory node, service, schema or table now retires the entity and its descendants instead of deleting them; the rows survive and stay readable with `include_retired=true`, and a new `POST /{id}/revive` clears retirement. No inventory entity is permanently removed until collection lands in SEP-1892. Revival is reachable through the Inventory API only — the admin UI still presents the operation as a permanent delete and has no revive action of its own.
