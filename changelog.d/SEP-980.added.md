Database-backed runtime overrides for a curated set of hot-reloadable SEP configuration fields. Admins write rows to the per-service settingoverride table; SEP and Tasks API processes refresh their snapshot every SETTINGS_OVERRIDE_REFRESH_INTERVAL (default 30s) and the new value takes effect on the next read. HOT in this release: SEPSettings (CONNECTIVITY_CHECK_DEFAULT, ARTIFACT_DOWNLOAD_TTL, SYNC_REFRESH_TIME), TasksSettings (PRE_EXECUTION_CONNECTIVITY_CHECK, STALENESS_THRESHOLD_SECONDS), SnippetsSettings (ENABLE_MANUAL_SYNC, PREVIEW_MAX_CHARS, PREVIEW_MAX_LINES), MessagesSettings (LEVEL). Inventory has no HOT fields and skips the refresher. Inventory/Tasks API endpoints, PMM endpoint, Celery-side fields, and snippets sync interval are intentionally NOT_OVERRIDABLE -- they are baked into long-lived objects that the snapshot refresh cannot reach without follow-up work tracked in SEP-1037 / SEP-1038 / SEP-1039.
