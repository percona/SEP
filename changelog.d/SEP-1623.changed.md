Clarify MySQL backup encryption options with grouped labels, inline help, and validation blocking invalid combinations. In-place (`encrypt`) and post-run (`post_run_encrypt`) encryption are independent modes that each produce an encrypted backup; either one requires an encryption recipient. Saved tasks that pair `encrypt_using_tmpdir` with `post_run_encrypt`, use `encrypt_using_tmpdir` without `encrypt`, or set `post_run_encrypt` without a recipient must be re-saved with a valid combination.
