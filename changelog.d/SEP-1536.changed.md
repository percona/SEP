MongoDB Restore is now exposed as a sibling "Restore" tab under MongoDB Backups and its JSON API moved from `/api/apps/backup_mongo/restores/` to `/api/apps/backup_mongo/restore/` (the Restore UI route is unchanged); both the MySQL and MongoDB Restore apps are now structurally bound to their parent Backups app — mounted and enabled or disabled together with it, and no longer independently toggleable.
