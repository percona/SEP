A syncer threshold set through the SEP__SYNCER_EXTRA_KWARGS__ env form is now checked when settings load, so an unusable STALE_RUN_AFTER or MISSING_GRACE_GENERATIONS value fails startup with the accepted forms named instead of making every inventory sync trigger return HTTP 500. Should such a value still reach syncer construction, the sync trigger answers HTTP 503 naming the syncer and the field rather than failing with an unhandled error.
