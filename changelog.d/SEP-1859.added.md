Inventory nodes, services, schemas and tables now report when a syncer last confirmed them against their source and whether syncing is currently failing, through four new read-response fields: last_synced_at, last_sync_error, sync_failing_since and consecutive_failures. The fields populate only where a syncer is scheduled, and each syncer fills only the levels whose fields it mirrors — the PMM syncer nodes and services, the MySQL syncer schemas and tables.
