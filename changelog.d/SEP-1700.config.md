Add the advanced hot override TASKS.NOMAD.LOG_ANONYMIZATION_MAX_WITHHELD_BYTES (default 1 MiB, must be positive) to bound how long task-log anonymization may withhold an un-terminated line. Existing deployments pick up the default with no configuration change; an override via NOMAD__log_anonymization_max_withheld_bytes takes effect on the next log sync or live-stream frame without a deploy. Setting it very low effectively disables line-boundary anonymization.
