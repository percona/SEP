`SEP_PLUGINS_BACKUPS_DISABLE` env var is renamed to `SEP_PLUGINS_MYSQL_BACKUPS_DISABLE`; any `SEP_ENABLED_PLUGINS` value containing `backups` must be updated to `mysql_backups`; the `/backups/*` URL path is removed — bookmarks, dashboards, and scripts referencing it will 404; `settings.yaml` deployment overrides `MODULE_NAME: backup` / `URI_PATH: /backups` must be changed to `mysql_backups` / `/mysql_backups`.
