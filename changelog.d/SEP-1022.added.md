SEP now runs a daily Celery beat check on the configured Nomad TLS files (CA and client PEM) and opens or resolves PagerDuty alerts (via `ALERTING.PROVIDERS`) when a certificate is inside the configured warning window before `not_valid_after` (default: 7 days). The threshold is set with `TASKS.NOMAD.CERT_EXPIRY_WARN_DAYS` in `settings.yaml`.
