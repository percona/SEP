Diagnostic script summaries now report whether a script's elevation is never wanted, optional or mandatory, and `GET /api/sep/hosts/` reports whether each host can run privileged work as able, unable, or never observed — so a client can warn before dispatch instead of after. The host fact is measured by the system-facts sync, which makes it available on different terms per deployment: the PMM-embedded profile collects it daily without operator action, while a standalone install seeds no inventory-sync schedule by default and therefore reports never-observed until a sync is triggered explicitly or an operator attaches an interval. In either profile a host reads never-observed until its first sync completes, and permanently so for an executor host with no inventory match.
