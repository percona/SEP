Declarative conditional-rule primitives for plugin schemas: `BaseField.requires` / `BaseField.forbidden` (FieldGate), `FormSection` / `PluginSchema` `cardinality_rules` (CardinalityRule) and `fail_when` (FailRule), authored via a typed predicate DSL (`F()`, `truthy`, `all_`, `any_`, `xor_`, `not_`, etc.) and enforced at runtime via `ConditionalRulesModel` + `apply_conditional_rules`.
