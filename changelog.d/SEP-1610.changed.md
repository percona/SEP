Snippets list search, filtering, and sorting now run server-side over the whole dataset — including a dedicated service-type facet endpoint offering every service type in the dataset, not only those on the loaded page — so results and the displayed total reflect every snippet. Blank, absent, and free-form service types (including tab/newline-padded values and one literally equal to `all`) are normalized through one shared definition, so the filter and its total always agree — the row's service label matches the facet, treating only space-padding as blank. Approving or removing approval under an active approval filter drops the affected row and adjusts the total immediately, and the list snaps back to the last populated page instead of stranding an empty one when a mutation shrinks the filtered total.
