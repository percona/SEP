Snippets list search, filtering, and sorting now run server-side over the whole dataset — including a dedicated service-type facet endpoint offering every service type in the dataset, not only those on the loaded page — so results and the displayed total reflect every snippet. Blank, absent, and free-form service types (including tab/newline-padded values and one literally equal to `all`) are normalized through one shared definition, so the filter and its total always agree.
