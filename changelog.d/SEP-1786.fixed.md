MySQL Backups now treats the XtraBackup incremental cycle numbers as ISO weekdays throughout. `XTRABACKUP_INCREMENTAL_CYCLE=1` (Monday) is now accepted — previously every weekday except Monday was expressible by number — and the Incremental cycle dropdown names each numeric option by the weekday it selects instead of labelling it as a day count. A saved cycle of `3` now reads `Wednesday` where it read `3 days`; the schedule is unchanged, but operators who read the old label as a three-day interval should re-check their cadence. The setting governs the `less_space` incremental method only.
