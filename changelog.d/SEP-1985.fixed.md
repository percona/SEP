MySQL Backups rejects a GPG encryption timing no backup engine reaches without an upload provider, instead of accepting it and finishing a successful plaintext backup. Only the pure GPG format is affected: `dual` keeps XtraBackup's built-in AES-256 pass whatever the GPG timing says, so no plaintext backup ships there. Tasks already saved in the rejected shape keep their stored form and still open in the edit form, but saving one now fails validation until an upload provider is selected or the unreachable timing is cleared. A read-only `form_audit` command reports which saved tasks those are.
