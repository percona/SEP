The PMM-embedded deployment now refreshes its inventory cache from PMM every 15 minutes with no operator action, starting at the first tasks-service restart after upgrade; an install that deliberately left the sync unscheduled begins syncing then, unless the environment variable TASKS__INVENTORY_SYNC_INTERVAL is set to null before that restart (the setting is read once at startup and is not a runtime-overridable one, so it cannot be changed from the settings admin UI). An install that already attached its own inventory-sync interval keeps exactly that interval.
