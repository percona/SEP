Refuse a second concurrent inventory sync run of the same syncer deterministically, so two workers starting at once can no longer both own the run and spend the retirement grace period in one moment.
A sync run left behind by a hard-killed worker now blocks new runs of that syncer until it ages past the syncer's stale-run window (1 hour by default), where previously it blocked nothing; the exclusivity guarantee applies on PostgreSQL, and SQLite-backed deployments are unchanged.
