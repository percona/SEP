The MySQL XtraBackup, binlog and MyDumper backup payloads, the MySQL XtraBackup restore, the PostgreSQL backup, the MongoDB PBM logical, physical and snapshot backups, the ALTER pre-checks, the post-create connectivity check and the MySQL inventory sync now load on Python 3.9 executor hosts when `TASKS.NOMAD.MINIFY_PAYLOAD` is off, where they previously failed at import; the fix takes effect on the next dispatch after the upgrade. With the setting at its default (on), these payloads already loaded. Executor hosts need `python3` 3.9 or newer with its `venv` module (Red Hat and Oracle Linux 8 hosts need a newer `python3` than their default 3.6, and Debian and Ubuntu hosts need `python3-venv`); see §4.4 of `docs/customer/nomad-driver-deployment.md`.
