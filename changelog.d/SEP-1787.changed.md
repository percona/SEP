PostgreSQL Backups now validates the incremental cycle when a task is saved. The field is a dropdown of daily, weekly, and ISO weekdays (Monday through Sunday); values outside that set return 422 instead of failing later on the database host. Tasks that already have a saved form must pick a valid option before the form will save. Legacy tasks whose stored cycle is outside that set are skipped by form backfill and cannot be edited in the UI until they are recreated.
