A PMM-embedded side-car that supplies AUTH__PROVIDER__GRAFANA__SERVICE_ACCOUNT_TOKEN or PMM__API_KEY — as an environment variable or a SECRETS_DIR file — now also exports that value to TASKS__NOMAD__API_KEY without minting a fresh Grafana token. When both mint-gate names differ, the service-account token wins; an explicit or mounted TASKS__NOMAD__API_KEY is left alone. See sidecar/README.md.
