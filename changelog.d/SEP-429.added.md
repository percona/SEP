MongoDB PBM (Percona Backup for MongoDB) backup diagnostics snippet (`mongodb_pbm_diagnostics.sh`) that collects `pbm config --list`, `pbm list`, `pbm logs`, and `pbm status`, plus the `pbm-agent` service unit and journal, from a node involved in a backup or restore. The PBM MongoDB URI is auto-detected from the `pbm-agent` service environment and its password is redacted from the output. Optionally appends the tail of the local MongoDB server log for post-restore troubleshooting.
