DB-backed runtime overrides for HOT Tasks settings (e.g. SYNC_LOCK_TTL) now take effect in the Celery worker without a restart, matching the API processes. AnonymizerSettings is also wrapped for overrides and DEFAULT_ENTITIES is hot-reloadable, but ANONYMIZER_SETTINGS is refreshed only in the worker: a DEFAULT_ENTITIES override is not yet observed by the API processes, nor by the worker's task-dispatch anonymization mask (which reads the persisted mask). Wiring those paths is a follow-up.
