The installer now serves the React SPA by default; set `SEP_SERVE_FRONTEND=0` to restore the legacy Jinja UI. Nginx now also proxies `/artifacts/` to the backend, so the signed artifact-download URLs handed to remote script executors keep resolving when the SPA is served. The new default requires a SEP image that carries the React bundle at `/home/sep/app/frontend/dist`; without it the `frontend-init` step fails and nginx does not start.
