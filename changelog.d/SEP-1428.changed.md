Archives create/update JSON body now uses discriminated one-of groups (source / destination / destination-host) with collapsed free-solo schema/table/service reference fields, replacing the separate id/name field pairs.
Archives task responses now expose the framework's connectivity-warning and PII-anonymization fields (`connectivity_warning`, `anonymize_mask`, `anonymized_entities`); the create/update response consolidates onto `ArchivesTaskResponse` and the separate `ArchivesCreateResponse` schema is removed.
