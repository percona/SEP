Archives, PostgreSQL Backups, MongoDB Backups, MySQL Restores and MongoDB Restores now show the username in Created By, and in the API's `created_by` and `last_updated_by` fields, instead of the stored user ID on their list, detail, create and update responses. The user list is cached for up to five minutes, so a user created or renamed within that window can still show the ID or the previous name, and if the auth provider cannot be reached the stored ID is shown.
