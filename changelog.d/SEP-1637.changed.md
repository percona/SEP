MySQL Backups now takes an explicit encryption format (none, GPG, AES-256, or AES-256 + GPG) instead of inferring one from whichever encryption fields were filled in, and the AES-256 key-file field moves into the Encryption section beside the GPG fields. The format is validated for every backup type, and it drives the XtraBackup backup script; Mydumper and Binlog have no AES-256 path, so they keep reading the GPG timing fields, which say the same thing. Existing tasks keep the encryption they already ran.
