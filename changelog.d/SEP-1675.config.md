Narrow TASKS.ANONYMIZER.DEFAULT_ENTITIES to seven high-confidence PII types (CREDIT_CARD, EMAIL_ADDRESS, IBAN_CODE, IP_ADDRESS, PHONE_NUMBER, US_SSN, US_ITIN) in the default profile. Deployments using the shipped settings.yaml no longer redact PERSON, LOCATION, NRP, US_BANK_NUMBER, US_PASSPORT, US_DRIVER_LICENSE, or MEDICAL_LICENSE by default. The development profile disables anonymization with an empty list.
