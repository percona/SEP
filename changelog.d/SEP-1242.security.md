Cookie-authenticated cross-site JSON mutations to `/api/plugins/*` (snippets, inventory, dipper, checksums, mysql_backups) are now rejected with `401`. `POST`/`PUT`/`PATCH`/`DELETE` requests to these endpoints must include `Authorization: Bearer <token>`; `GET`/`HEAD`/`OPTIONS` are unaffected. The 401 response body now uses a uniform path-agnostic detail string (`"Bearer authentication required for state-changing requests."`). Closes the CSRF bypass left after SEP-1061.
