State-changing API requests (POST, PUT, PATCH, DELETE) now require an administrator. Non-admin users keep full read access; deployments whose non-admin users write through the API must grant them admin. Under Grafana-backed auth this makes Editors read-only alongside Viewers, since only the server-admin flag or an org Admin role maps to admin. Where SEP is embedded in PMM, the restriction takes effect only once PMM exchanges each session for a per-user SEP bearer; until then every embedded request arrives as the internal service principal and no per-user restriction applies.
