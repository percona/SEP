An entity-style AppSchema (non-empty entities) that declares root-level forms, cardinality_rules, or fail_when now fails at plugin import instead of silently ignoring those keys; move them onto the relevant entity. In-tree plugins are unaffected — inventory is the only entity-style construction and sets no root form config — but out-of-tree or PMM-side plugins that relied on the old ignore behaviour must relocate root form config onto each entity before upgrading.
