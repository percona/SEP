Collect Diagnostic Data is now called Support diagnostics, in the sidebar and on the page. On a deployment where the SEPSettings key DIAGNOSTICS_DELIVERY_INPUTS was never supplied — or where a secret the baked DIAGNOSTICS_DELIVERY plan declares is stored empty or missing — the app is replaced by a screen explaining what the tool does and, for admins only, a link to Settings; it no longer lets a run reach the upload and fail there. The gate reads the admin-only settings API, so a read that fails or is forbidden lets the app render rather than showing the setup screen.
