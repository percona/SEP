Session assertions minted before this release carry no role claim and are refused rather than downgraded to a role derived from the admin flag. The upgrade effect depends on the deployment shape: a standalone Grafana-auth SPA session ends and the user signs in again, because both the in-memory access token and the `refreshToken` cookie are refused; a PMM-embedded session renews itself from the ambient Grafana session with no user action; and Casdoor deployments are unaffected, because Casdoor mints no SEP assertion. No new configuration is required.
