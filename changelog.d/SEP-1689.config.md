New `SETTINGS_OVERRIDE.ALLOWED_KEYS` setting (env var `SETTINGS_OVERRIDE__ALLOWED_KEYS`) restricts which settings the override API may write, as a default-locked allowlist of `ClassName.KEY` entries; unset (the default) leaves every deployment unrestricted, while the embedded side-car image ships with the restriction active, so its settings UI turns read-only outside the baked allowlist.
