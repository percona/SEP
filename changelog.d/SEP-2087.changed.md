Support diagnostics runs are now dispatched through an ATW-owned proxy task, so the task name reported for a batch execution changes, and newly dispatched diagnostics runs no longer appear in the Snippets per-script execution history pane. They remain listed on the incident's own executions view, which is where incident-scoped runs belong. Task-history display labels are unaffected: a proxy over a generic executor is classified by the task it wraps, so a run still shows its snippet and target.
