Support diagnostics runs are now dispatched through an ATW-owned proxy task, so the task name reported for a batch execution changes, and newly dispatched diagnostics runs no longer appear in the Snippets per-script execution history pane. They remain listed on the incident's own executions view, which is where incident-scoped runs belong. A diagnostics run's task-history display label still shows its snippet and target, because a proxy that leaves the script to each dispatch is labelled by the task it wraps; backup, restore and other app tasks keep showing their own configured names.
