Task-plugin list columns and detail fields can now carry a per-value display-label map in the app schema, so a client rendering an enum-valued field has human-readable text available instead of only the stored code. The backup apps' "Type" column and the PostgreSQL detail field publish their labels; consuming them in the UI lands separately, so the rendered value is unchanged in this release. A client that ignores the new field sees a byte-identical schema. Separately, the MySQL restore backup-source selector now labels binlog backups as "Binlog" rather than showing the raw "B".
