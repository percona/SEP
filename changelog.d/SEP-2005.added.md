Task-plugin list columns and detail fields can now carry a per-value display-label map in the app schema, so a client rendering an enum-valued field has human-readable text available instead of only the stored code. The backup apps' "Type" column and the PostgreSQL detail field publish their labels; consuming them in the UI lands separately, so the rendered value is unchanged in this release. The new field is optional and additive: an app that declares no labels serves the same schema it did before, and a client that ignores the field behaves exactly as it did before.
