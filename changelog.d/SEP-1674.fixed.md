PostgreSQL Backups now correctly triggers FULL backups per the configured incremental cycle. Previously, a config-key mismatch (`PG_*` instead of `PGBACKREST_*`) and a type mismatch in the weekday comparison meant a FULL backup could never run. Tasks whose incremental cycle is set to anything other than `daily`, `weekly`, or `1`-`7` now fail with a configuration error instead of silently running incremental backups only; review saved tasks before upgrading.
