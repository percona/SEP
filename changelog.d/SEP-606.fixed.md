The Nomad executor now authenticates with a configured `TASKS.NOMAD.API_KEY`, sent as `Authorization: Bearer <key>` by default and taking precedence over any credentials embedded in `TASKS.NOMAD.ENDPOINT`; the PMM-embedded side-car fans its own minted Grafana token out to it, so a deployment that lets the side-car mint its own token no longer needs an operator password in the endpoint URL.
