XtraBackup tasks now dispatch a payload variant carrying only the upload providers the task selected, reclaiming up to 1,718 bytes of the 16 KiB Nomad dispatch limit, and request `boto3` only when an S3 provider ships. A backup that names an upload provider its payload cannot reach now fails instead of logging a warning and reporting success with no offsite copy; backup behaviour is otherwise unchanged. This reaches tasks created or updated after the upgrade; an existing stored task keeps its recorded payload reference, and the full-provider payload it points at still ships.
